# 國文辭典查詢工具

給華語／國文老師備課用的桌面小工具。貼上一篇課文，就能查出每個詞的注音、詞類、釋義和 TBCL 等級，整理成生字表、生詞表、練習題，也能下載教育部的筆順動畫。

Windows 和 Mac 都能用，下載後直接打開，不用安裝。

## 下載

| 電腦 | 下載 | 打開方式 |
|---|---|---|
| **Windows** 10／11 | **[下載 Windows 版（CNdict-tool.exe）](https://github.com/Peggy2005/CNdict-tool/releases/latest/download/CNdict-tool.exe)** | 雙擊執行 |
| **Mac**（Apple M1／M2／M3／M4 晶片） | **[下載 Mac 版（CNdict-tool-mac.zip）](https://github.com/Peggy2005/CNdict-tool/releases/latest/download/CNdict-tool-mac.zip)** | 解壓縮後，把「國文辭典查詢工具」拖進「應用程式」資料夾 |

所有版本與更新紀錄：[Releases](https://github.com/Peggy2005/CNdict-tool/releases)

> 不確定 Mac 是哪種晶片？點左上角  →「關於這台 Mac」，「晶片」寫 Apple M 開頭就能用。2020 年以前的 Intel Mac 目前不支援。

### 第一次打開被擋下怎麼辦

程式沒有付費的數位簽章，第一次打開時系統會提醒，照下面做一次就好：

- **Windows**：出現「Windows 已保護您的電腦」→ 按「其他資訊」→「仍要執行」。如果被 Microsoft Defender 或瀏覽器擋下，請在下載紀錄選「保留」。
- **Mac**：出現「無法打開，因為 Apple 無法檢查是否有惡意軟體」→ 先按「完成」，到「系統設定」→「隱私權與安全性」，往下找到這個程式，按「強制打開」。之後如果詢問「要允許『CNdict-tool』尋找區域網路上的裝置嗎？」，請按「允許」（程式是在你自己的電腦上開一個小伺服器來顯示畫面，不會連到其他裝置）。

## 功能

**查詞**
- 輸入幾個詞，或貼上整篇文章（也可以把 txt／docx／pdf 拖進視窗）
- 用國教院「教材編輯輔助系統」斷詞，查出注音、漢語拼音、詞類、釋義、英文對應和 TBCL 等級
- 可加上近義詞／反義詞欄，結果下載成 Excel

**備課**
- 一課存成一個專案，下次打開接著做
- 分析課文難度：依 TBCL 估計詞彙參考程度，標出超過學生程度的詞
- 整理生字表、生詞表、成語學習單（Word），近反義詞改寫
- 產生練習題，可以逐題修改
- 一鍵下載整課備課包

**筆順**
- 顯示教育部《國字標準字體筆順學習網》的官方筆順動畫
- 下載白底 MP4（單字，或整批打包成 zip），方便放進簡報

## 使用須知

- 需要網路：查辭典、斷詞、筆順動畫都是連線即時查詢
- 下載筆順影片時，電腦上需要有 Chrome 或 Edge
- 每次開啟需要等幾秒鐘載入
- 匯出的 Excel、Word、zip、MP4 會跳出「另存新檔」，自己選要存在哪裡

## 資料來源

- 國家教育研究院「教材編輯輔助系統」斷詞、《臺灣華語文能力基準》（TBCL）詞語分級、華英雙語索引典
- 教育部《國語辭典簡編本》、《重編國語辭典修訂本》（含相似詞、相反詞索引表）、《成語典》、《國語小字典》、萌典
- 教育部《國字標準字體筆順學習網》筆順動畫（CC BY-NC-ND 3.0 TW，僅供非商業教學使用）
