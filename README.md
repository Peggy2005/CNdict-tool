# 國文辭典查詢工具

給國文／華語教學用的 Windows 小工具：查詞表格、近義詞替換、教育部筆順動畫，一個程式搞定。

## 下載

**[直接下載最新版 CNdict-tool.exe](https://github.com/Peggy2005/CNdict-tool/releases/latest/download/CNdict-tool.exe)**（或到 [Releases](https://github.com/Peggy2005/CNdict-tool/releases) 看所有版本），雙擊執行（不用安裝），會自動打開瀏覽器。

## 功能

- **查詞表格**：輸入詞彙或整篇文章（可拖入 txt／docx／pdf），自動斷詞並查出音標、詞類、意思、詞彙等級，可下載 Excel
- **近義詞替換**：選一段文字，把詞換成教育部《重編國語辭典修訂本》相似詞，輸出改寫句與詞表
- **筆順動畫**：顯示教育部《國字標準字體筆順學習網》官方筆順動畫，可下載白底 MP4（單字或整批 zip）
- 內建分頁式「新手教學」

## 使用須知

- 需要網路（查辭典、斷詞、筆順動畫都是即時查詢）
- 筆順影片錄製需要電腦上有 Chrome 或 Edge
- 第一次執行 Windows 可能跳出「Windows 已保護您的電腦」（程式沒有數位簽章）：按「其他資訊」→「仍要執行」
- 每次開啟約需 5–10 秒解壓縮

## 資料來源

- 國家教育研究院《教材編輯輔助系統》斷詞、詞彙分級表
- 教育部《國語辭典簡編本》、《重編國語辭典修訂本》、萌典
- 中華民國教育部《國字標準字體筆順學習網》筆順動畫（CC BY-NC-ND 3.0 TW，僅供非商業教學使用）
